# Registration Form Project

## Overview
This project is a **responsive registration form** built using **HTML** and **CSS**.  
It allows users to enter personal information, select their program, upload documents, and submit their registration. The design is modern, clean, and interactive, with smooth hover effects.



## Features
- Fully **responsive layout** (mobile & desktop friendly)
- **Custom styled input fields** with hover and focus effects
- **Gender selection** with radio buttons
- **Program selection** via dropdown menus
- **File upload** functionality
- **Interactive hover effects** on images and headings
- Gradient backgrounds and **glassmorphism-inspired** container design
